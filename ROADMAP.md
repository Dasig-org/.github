# Roadmap

Where Bayanihan is going, and where you can help. It's early, and plans change as we learn from the groups using it.
Dates appear only once I'm sure of them.

## The mission

Many groups work on the same problem in the same city: a city's nutrition programme, for example, run by the city
and a foundation together with dozens of nonprofits, schools and volunteer groups. Today each group reports in its
own way, by email and spreadsheet, and nobody sees the whole picture until long after.

I want a coordinating organization (an LGU, a foundation, a federation) to be able to set up an advocacy, have the
groups working on it join in, and let everyone (the coordinators, the groups and the public) follow how the work is
going, from updates the groups already post. A shared, public tracker. It's a small, practical step towards
reporting on the Sustainable Development Goals from the ground up.

We don't know yet what these reports should look like. We'll work it out with the coordinators and groups who use
it, one mission at a time, and build the infrastructure slowly.

Much of the foundation is already designed in [BIX](https://github.com/Dasig-org/bix): shared Goals, causes mapped
to the SDGs, who a project serves, projects enrolling in a Goal, and reports that add up across groups. Most of it
isn't built yet.

## Now · until late January 2027

**Real groups, a steady app.** No new features for now. We're helping groups use the Dasig app for real work and
fixing what gets in their way.

- Fix what groups and contributors run into
- Make contributing easy: setup, checks on every pull request, good first issues
- Test Bayani on real projects and on 4 GB Android phones

## Next

**A shared advocacy tracker** (Dasig app, Bayanihan Core and Server). Milestone: *Shared advocacy tracker v0*.

- A coordinating organization sets up a Goal for a place and a cause
- Groups enroll their projects; the coordinator accepts
- A public page for the Goal: who's taking part, recent updates, and progress from the groups' reports
- A coordinator's view: which groups have reported, what's behind, where help is needed
- Report shapes co-designed with the first coordinators who try it

**Money in BIX** (BIX v0.2). Milestone: *BIX v0.2: money in a project*.

- Financials: a project's budget, what was spent, receipts
- Fundraising: what was raised for a project, from whom (or anonymously), towards which need
- Grantmaking: applications, awards, disbursements, and the reports a grantee owes a funder

I'm looking for **volunteer federations and organizations with experience in grants and fundraising** to shape this
with us. If that's you, open a discussion or email hello@dasig.org.

## Later

- Hosting a Goal on your own Bayanihan Server, and servers that federate
- Baseline data for a Goal from the Humanitarian Data Exchange (HDX), so coordinators see where the gaps are
- Mappings to the standards others already use: OCHA 3W, IATI for funding, and Open Referral for services
- Bayani learning from real projects: openly licensed humanitarian guides first, then real project plans shared
  with consent
